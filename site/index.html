rsqldev

A native SQL client in the style of Oracle SQL Developer, multi-database like DBeaver — without Java. Real macOS, Windows and Linux (GTK) windows, using roughly 4–8× less memory.

Download for macOSApple Silicon & Intel · macOS 11+ Download for WindowsWindows 10 / 11 · 64-bit Download for LinuxIntel/AMD 64-bit · Ubuntu 22.04+, Debian 12+, Fedora 36+

Linux on ARM: ARM 64-bit (Raspberry Pi 4/5 with a 64-bit OS, ARM servers). 64-bit only.

All versions and release notes: Releases. Source code: github.com/kokohbudi/rsqldev.

Install

macOS

  1. Download rsqldev-macos-universal.zip and double-click it to unzip. One download runs natively on both Apple Silicon and Intel Macs.
  2. Move rsqldev.app to Applications.
  3. The app is not notarized by Apple, so the first launch is blocked: right-click rsqldev.app → Open → Open. Only needed once.

If macOS says the app is “damaged”, run this in Terminal and open it again:

xattr -dr com.apple.quarantine /Applications/rsqldev.app

Windows

  1. Download rsqldev-windows-x64.zip, right-click → Extract All…
  2. Open the extracted folder and run rsqldev.exe.
  3. If SmartScreen shows “Windows protected your PC”, click More info → Run anyway.

Linux

tar xzf rsqldev-linux-x86_64.tar.gz
rsqldev-linux-x86_64/install.sh      # installs to ~/.local/bin and adds a menu entry

Needs GTK 3 (present on any desktop install). Oracle needs libaio: Debian/Ubuntu sudo apt install libaio1 (Ubuntu 24.04: libaio1t64, then sudo ln -s /usr/lib/x86_64-linux-gnu/libaio.so.1t64 /usr/lib/x86_64-linux-gnu/libaio.so.1), Fedora sudo dnf install libaio. Other databases need nothing extra.

Getting started

1. Create a connection

  1. File → New Connection… (Ctrl/Cmd+Shift+C).
  2. Pick the Database Type, fill in host, port, database / service name, user and password. Tick Save Password to keep it in the macOS Keychain, Windows Credential Manager or the Linux Secret Service.
  3. Click Test, then Connect.

Oracle: on first connect rsqldev offers to download Oracle Instant Client (SHA-256 checked). Also under Tools → Drivers….

2. Run SQL

ActionShortcut
Run the statement under the cursorCtrl/Cmd+Enter
Run as script (every statement, incl. PL/SQL and SQL*Plus commands)F5
Explain planF10
Commit / RollbackF11 / F12
Complete tables and columnsCtrl+Space, or automatically after typing alias.
Format SQLCtrl/Cmd+F7
Find / ReplaceCtrl/Cmd+F / Ctrl/Cmd+R, then F3 / Shift+F3
SQL historyF8
Cancel a long queryCtrl/Cmd+.

While a query runs, the bar at the bottom right shows that it is working and for how long.

3. Browse and edit data

  • Double-click a table in Connections → Data tab. Edit cells in place, insert or delete rows, then Commit.
  • The Filter box takes a WHERE clause, e.g. status = 'ACTIVE'.
  • Right-click a cell: View Value… (long text / CLOB, BLOB as image, text or hex), Save Value to File…, Load Value from File… (BLOB upload).

4. Import and export

  • Export: right-click a result grid → CSV, Excel (xlsx), JSON or INSERT statements.
  • Import: Data tab → Import button → a CSV, xlsx, xls or ods file. Columns are matched by header name; rows arrive as new rows to review, then Commit. If any row fails, everything is rolled back.

Advanced connections

Use the Options field of the connection dialog, separated by semicolons:

NeedOptions
SSH tunnel / bastion hostssh=user@bastion:22; ssh_key=~/.ssh/id_ed25519
Key or ssh-agent authentication (no passwords). Uses the OpenSSH client that ships with macOS, Linux and Windows 10+.
PostgreSQL with certificate verificationsslmode=verify-full
Local SQL Server with a self-signed certificatetrust_cert=true
MySQL over SSLssl=true (add verify=false for a self-signed certificate)
ClickHouse over HTTPShttps=true (port 8443)
Oracle wallet / tnsnames.oratns_admin=/path/to/folder

Build from source

git clone https://github.com/kokohbudi/rsqldev
cd rsqldev
cargo run --release -p rsqldev          # run it
scripts/bundle-macos.sh --install       # macOS: universal .app into ~/Applications
scripts/build-linux.sh x86_64           # Linux tarball via Docker (x86_64 or aarch64)

Needs Rust (rustup) and CMake; on Linux also libgtk-3-dev and libssl-dev. For the universal macOS app: rustup target add aarch64-apple-darwin x86_64-apple-darwin.
