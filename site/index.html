rsqldev

SQL client native ala Oracle SQL Developer, multi-database seperti DBeaver — tapi tanpa Java. Jendela asli macOS dan Windows, pakai memory sekitar 4–8× lebih kecil.

Download untuk macOSApple Silicon & Intel · macOS 11+ Download untuk WindowsWindows 10 / 11 · 64-bit

Semua versi & catatan rilis: halaman Releases. Kode sumber: github.com/kokohbudi/rsqldev.

Instalasi

macOS

  1. Download rsqldev-macos-universal.zip, lalu klik dua kali untuk ekstrak.
  2. Pindahkan rsqldev.app ke folder Applications.
  3. Pertama kali dibuka, macOS akan menolak karena aplikasi belum ditandatangani Apple. Klik kanan rsqldev.app → Open → Open. Cukup sekali.

Kalau muncul pesan “rusak / damaged”, jalankan di Terminal lalu buka lagi:

xattr -dr com.apple.quarantine /Applications/rsqldev.app

Windows

  1. Download rsqldev-windows-x64.zip, klik kanan → Extract All…
  2. Buka folder hasil ekstrak, jalankan rsqldev.exe.
  3. Kalau SmartScreen muncul (“Windows protected your PC”), klik More info → Run anyway.

Mulai pakai

1. Buat koneksi

  1. Menu File → New Connection… (Ctrl/Cmd+Shift+C).
  2. Pilih Database Type, isi host, port, database/service name, user, password. Centang Save Password kalau mau (disimpan di Keychain / Windows Credential Manager).
  3. Klik Test, lalu Connect.

Oracle: saat pertama konek, rsqldev menawarkan download Oracle Instant Client (cek checksum SHA-256). Bisa juga lewat Tools → Drivers….

2. Jalankan SQL

AksiShortcut
Run statement di bawah kursorCtrl/Cmd+Enter
Run script (semua statement, termasuk PL/SQL & perintah SQL*Plus)F5
Explain planF10
Commit / RollbackF11 / F12
Autocomplete tabel & kolomCtrl+Space, atau otomatis setelah ketik alias.
Format SQLCtrl/Cmd+F7
Find / ReplaceCtrl/Cmd+F / Ctrl/Cmd+R, lalu F3 / Shift+F3
SQL historyF8
Batalkan query yang lamaCtrl/Cmd+.

Selama query jalan, progress bar di kanan bawah menunjukkan durasinya, jadi aplikasi tidak terlihat hang.

3. Lihat dan edit data

  • Klik dua kali tabel di panel Connections → tab Data. Edit cell langsung, tambah/hapus baris, lalu Commit.
  • Kolom Filter menerima klausa WHERE, contoh status = 'ACTIVE'.
  • Klik kanan cell: View Value… (teks panjang / CLOB, BLOB sebagai gambar / teks / hex), Save Value to File…, Load Value from File… (upload BLOB).

4. Import & export

  • Export: klik kanan grid hasil → CSV, Excel (xlsx), JSON, atau INSERT statement.
  • Import: tab Data → tombol Import → pilih CSV / xlsx / xls / ods. Kolom dicocokkan dengan nama header; baris masuk sebagai baris baru untuk dicek dulu, lalu Commit. Kalau ada yang gagal, semuanya di-rollback.

Koneksi lanjutan

Isi kolom Options di dialog koneksi, dipisah titik koma:

KebutuhanOptions
Lewat SSH tunnel / bastionssh=user@bastion:22; ssh_key=~/.ssh/id_ed25519
Pakai key atau ssh-agent (bukan password). Butuh OpenSSH client — sudah ada di macOS dan Windows 10+.
PostgreSQL dengan verifikasi sertifikatsslmode=verify-full
SQL Server lokal dengan sertifikat self-signedtrust_cert=true
MySQL lewat SSLssl=true (tambah verify=false untuk sertifikat self-signed)
ClickHouse lewat HTTPShttps=true (port 8443)
Oracle wallet / tnsnames.oratns_admin=/path/ke/folder

Build sendiri dari source

git clone https://github.com/kokohbudi/rsqldev
cd rsqldev
cargo run --release -p rsqldev          # langsung jalan
scripts/bundle-macos.sh --install       # macOS: buat .app universal, pasang ke ~/Applications

Butuh Rust (rustup) dan CMake. Untuk app universal macOS: rustup target add aarch64-apple-darwin x86_64-apple-darwin.
